# hijri_toolkit example

A tiny Flutter app showing how to display the same Hijri date in Arabic and
English with `HijriText`.

Run it from this directory:

```sh
flutter pub get
flutter run
```

The app renders:

- Arabic: `الثلاثاء، ١ محرم ١٤٤٥`
- English: `Tuesday, 1 Muharram 1445`
- Gregorian source: `2023-07-18`
